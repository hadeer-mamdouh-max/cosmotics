# NŌRA Beauty Studio

واجهة هبوط عربية RTL لاستوديو عناية وجمال، مبنية باستخدام React و Vite.

## التشغيل

```bash
npm install
npm run dev
```

شغّلي خادم الحجوزات في طرفية ثانية:

```bash
npm run server
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

تتضمن الصفحة برامج العناية، متجر المنتجات، نموذج حجز متصل بـ Express API، ولوحة تحكم يمكن فتحها من زر "لوحة التحكم". تحفظ الحجوزات محليًا في `server/data/bookings.json`، ويمكن استبدال التخزين لاحقًا بقاعدة بيانات.
