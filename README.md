# NŌRA Beauty Studio

واجهة هبوط عربية RTL لاستوديو عناية وجمال، مبنية باستخدام React و Vite.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

تتضمن الصفحة برامج العناية، متجر المنتجات، نموذج حجز تفاعلي، ولوحة تحكم تجريبية يمكن فتحها من زر "لوحة التحكم".
